🐍 Python Basics: Summation & String InversionЛаскаво просимо до навчального репозиторію, де зібрані фундаментальні алгоритми на Python. Цей проект демонструє роботу з динамічними аргументами та маніпуляції з текстовими рядками.🚀 Функціонал проектуРепозиторій містить два ключових інструменти:1. Універсальний суматор (sum_all)Функція, яка не має меж! Ви можете передати їй будь-яку кількість чисел, і вона миттєво поверне їх суму.Технологія: Використання оператора *args.Приклад: sum_all(1, 5, 10) → 16.2. Реверс рядка з форматируваннямПрограма, яка приймає текст від користувача та розгортає його задом наперед, використовуючи системний символ перенесення рядка \n.Технологія: Слайсинг (зрізи) рядків [::-1].Приклад: Привіт → тівирП.💻 Як це працює?Магія *argsКоли ми додаємо зірочку перед аргументом, Python створює кортеж (tuple). Уявіть це як кошик, куди складаються всі ваші числа перед тим, як потрапити до функції sum().Магія зрізів [::-1]Рядок у Python — це впорядкована послідовність. Зріз [::-1] каже інтерпретатору: "Почни з останнього символу і йди до першого з кроком -1".🛠 Інструкція з використанняКлонуйте репозиторій:Bashgit clone https://github.com/ваш-юзернейм/python-basics.git
